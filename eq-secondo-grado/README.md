# Equazioni di secondo grado

Completa `script.js` per calcolare e mostrare le soluzioni dell'equazione `ax² + bx + c = 0`.

## Consegna

1. Leggi i valori di `a`, `b` e `c` dai campi di input.
2. Calcola il discriminante `Δ = b² − 4ac` e mostra le soluzioni:
   - `Δ > 0`: due soluzioni reali distinte;
   - `Δ = 0`: una soluzione doppia;
   - `Δ < 0`: nessuna soluzione reale.
3. Gestisci tutti i casi particolari mostrando un messaggio di errore.
