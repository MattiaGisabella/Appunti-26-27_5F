# Lista della spesa

Completa `script.js` per creare una lista interattiva in cui si possono **aggiungere** e **rimuovere** elementi dal DOM.

## Consegna

1. Al click sul bottone "Aggiungi" (o premendo Invio), aggiungi un nuovo `<li>` alla lista con il testo dell'input.
2. Ogni elemento deve avere un bottone "Rimuovi" che lo elimina dalla lista.
3. Se l'input è vuoto, mostra un messaggio di errore e non aggiungere nulla.
4. Dopo l'aggiunta, svuota il campo di input.
5. (Bonus) Al click sul testo dell'elemento, barralo come "fatto" usando la classe `done`.

Suggerimenti: usa `document.createElement`, `appendChild`, `remove()` e `addEventListener`.
